# Amazon Review Brands card

Adds an Amazon Reviews card to each existing contact card. Tapping it opens saved, user-verified brand names and allows one brand per line to be added/edited. It includes an Open Amazon Profile link and a best-effort refresh status that becomes due every four hours while the app is open.

Important: Amazon profile/review pages commonly block cross-origin scraping. This feature does not claim to extract brands automatically and never fabricates brand names. The user must verify brands on the opened Amazon profile and save them. A standard iPhone web app cannot guarantee four-hour background work while fully closed.

Preserves `dealDhamakaAgentV2`; review metadata is stored on each existing contact record and uses the existing save/backup pathway. No WhatsApp Cloud API or new tab added.
