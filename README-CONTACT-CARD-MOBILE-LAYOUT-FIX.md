# Contact card mobile layout fix

The contact card stacks contact identity/details above statistics on narrow screens. Shared, ordered, paid-line, paid-amount and pending badges use a responsive two-column grid with shrink-safe widths. Long WhatsApp numbers and Amazon profile links wrap within the card instead of forcing the contact column to collapse. On wider screens the details and stats use a two-column layout.

This package is based on the previous consolidated-payment-receipt-fix ZIP and retains its payment batching changes.
